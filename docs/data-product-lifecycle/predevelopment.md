# Pre-Development Phase

Fase Pre-Development dirancang khusus untuk organisasi yang membutuhkan kecepatan dalam pengiriman data, bahkan sebelum produk data dianggap matang. Pada fase ini, data diolah sesederhana mungkin dan disampaikan sesuai kebutuhan, meskipun belum ideal. Sementara itu, proses pengembangan produk data yang ideal tetap berjalan.

![Pre-Development Phase Flow](media/predevelopment_phase.jpg ':size=100%')


## Alur dan Langkah-langkah

1. **Temporary Space (Data Staging)**
   - **Deskripsi:** Menciptakan ruang sementara untuk menyimpan data yang akan diproses. Ini memungkinkan tim untuk mulai bekerja dengan data tanpa menunggu infrastruktur yang sepenuhnya matang.
   - **Output:** Data Sementara / Sampel
   - **Peran:** Insinyur Data (Bertanggung Jawab)

2. **Write Task Brief**
   - **Deskripsi:** Menyusun dokumen yang menjelaskan tugas-tugas yang perlu dilakukan untuk mempersiapkan infrastruktur dan pipeline data.
   - **Langkah-langkah:**
     - **Infra**
       - Menyusun **Infra Task Brief** yang mencakup kebutuhan infrastruktur dasar.
       - **Output:** Infra Task Brief
       - **Peran:**
         - Manajer Teknik Data (Bertanggung Jawab)
         - Analis Data (Mendukung)
         - Analis Tata Kelola Data (Informed)
         - Arsitek Data (Informed)
     - **Pipeline/Adhoc**
       - Menyusun **Pipeline/Adhoc Task Brief** untuk tugas-tugas yang bersifat sementara.
       - **Output:** Pipeline/Adhoc Task Brief
     - **API**
       - Menyusun **API Task Brief** untuk pengembangan API yang diperlukan.
       - **Output:** API Task Brief

3. **Setup**
   - **Deskripsi:** Membangun infrastruktur dan pipeline yang diperlukan untuk pengolahan data.
   - **Langkah-langkah:**
     - **Basic Infra**
       - Membangun database yang mencakup peran-peran database yang diperlukan.
       - **Output:** Database (termasuk Peran Database)
     - **Basic Pipelines/Adhoc**
       - Membangun pipeline data mentah (Datalake) untuk menyimpan data yang akan diproses.
       - **Output:** Raw Data Pipeline (Datalake)
       - Menyediakan datamart kustom berdasarkan permintaan pengguna.
       - **Output:** Custom Datamart upon Request
     - **Basic APIs**
       - Menghasilkan API dari Datamart secara otomatis untuk memudahkan akses data.
       - **Output:** API from Datamart (autogenerated)

4. **Team Reconciliation**
   - **Deskripsi:** Mengadakan pertemuan tim untuk merekonsiliasi tugas dan memastikan semua anggota tim berada pada halaman yang sama.
   - **Output:** Risalah Rapat
   - **Peran:** Data Ops (Bertanggung Jawab)

## Output RASCI

- **R**: Bertanggung Jawab
- **S**: Mendukung
- **I**: Informed

### Tanggung Jawab Peran

- **Insinyur Data**
  - Bertanggung jawab untuk pengolahan dan pengiriman data sementara.
  - Memastikan infrastruktur dasar dan pipeline data berfungsi.

- **Manajer Teknik Data**
  - Bertanggung jawab untuk menulis dan mengawasi pelaksanaan task brief infrastruktur.

- **Analis Data**
  - Mendukung dalam penyusunan dan pelaksanaan task brief.

- **Analis Tata Kelola Data & Arsitek Data**
  - Diberi informasi mengenai perkembangan dan struktur infrastruktur serta pipeline.

- **Data Ops**
  - Bertanggung jawab untuk rekonsiliasi tim dan dokumentasi risalah rapat.

Fase ini memungkinkan pengiriman data yang cepat dan efisien sambil tetap mengembangkan produk data yang ideal.
