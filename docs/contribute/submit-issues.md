# Melaporkan Permasalahan dan Keluhan

Dokumen Data Product Management Playbook ini secara terus-menerus akan dikembangkan oleh seluruh tim Data yang terlibat. Seiring dengan perkembangan organisasi JDS, tentu ada banyak aspek yang perlu dievaluasi, diimplementasi, dan dinilai. Jadi, masing-masing tim Data akan terlibat dalam proses penelitian dan pengembangan yang terus-menerus.

Untuk melaporkan permasalahan dan keluhan, silakan mengikuti prosedur berikut:

## Pembuatan `Issue` di GitHub.

Siapapun boleh membuat `Issue` di Github. Silakan mengikuti langkah-langkah berikut:

1. Buka halaman repositori di Github

https://github.com/jabardigitalservice/data-product-management-playbook/issues/

![Submit Issue](media/submit-issue.png ':size=100%')

2. Klik tombol "**New issue**"
3. Isi judul dan deskripsi

![Write Issue](media/write-issue.png ':size=100%')

4. Tandai sebagai `priority` (jika perlu)

5. Klik tombol `Submit new issue`

## Berkomunikasi terkait `Issue` di Github

Tim Data dapat berkomunikasi terkait `Issue` di Github melalui kolom komentar di halaman `Issue` yang dibuka.

![Write Comment](media/write-comment.png ':size=100%')

## Kategorisasi `Issue`

Ada tiga jenis kategori yang dapat digunakan untuk mengelompokkan `Issue`:

- **Bug**: Perbaikan perlu dilakukan pada bagian yang sudah ditulis sebelumnya
- **Feature**: Permintaan penambahan bagian baru baik di dokumen eksisting maupun atau dokumen baru
- **Task**: Set ini sebagai default jika tidak ada kategori yang sesuai

![Categorize Issue](media/categorize-issue.png ':size=100%')

## Penyelesaian `Issue`

Permasalahan atau keluhan akan dikoordinir dan dibuatkan perbaikan. Untuk memudahkan organisasi perbaikan dan dikaitkan dengan issue yang didaftarkan, kita bisa membuat branch baru atau melampirkan branch yang sudah ada di `Issue` tersebut.

Membuat branch baru dari halaman `Issue` bisa dilakukan dengan mengklik tombol `Development > Create a branch` yang terdapat di sebelah kanan halaman `Issue`.

![Create New Branch](media/create-branch.png ':size=100%')

Melampirkan branch yang sudah ada di `Issue` bisa dilakukan dengan mengklik tombol `Development > Link pull request` yang terdapat di sebelah kanan halaman `Issue`.

![Link Pull Request](media/link-pull-request.png ':size=100%')
