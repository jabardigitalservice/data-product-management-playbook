# Bootstrap Phase

Fase Bootstrap adalah tahap awal dalam proses Manajemen Data Product, yang berfokus pada identifikasi dan inisiasi domain dan produk data. Fase ini melibatkan beberapa langkah kunci, output, dan peran dengan tanggung jawab spesifik.


![Bootstrap Phase Flow](media/bootstrap_phase.jpg ':size=100%')

# Alur dan Langkah-langkah

1. **Identifikasi Awal Domain & Produk Data**
   - **Inisiasi Struktur Wiki**
     - **Output:** Struktur Wiki
     - **Peran:** Semua Anggota (Bertanggung Jawab)

2. **Registrasi Sumber Input Data**
   - **Output:** Entri Katalog Baru: Sumber Input Data
   - **Peran:**
     - Analis Tata Kelola Data (Bertanggung Jawab)
     - Insinyur Data (Bertanggung Jawab)

3. **Inisiasi Dokumentasi Domain Data**
   - **Output:**
     - Dokumen Wiki & Slide Presentasi: Dokumen Domain Baru dan Kepemilikan
     - Clickup: Epic Domain Data Baru dan Penugasan
     - Domain DataHub: Struktur Domain Baru
   - **Peran:**
     - Analis Tata Kelola Data (Bertanggung Jawab)
     - Arsitek Data (Mendukung)

4. **Inisiasi Dokumentasi Produk Data Baru**
   - **Output:**
     - Kanvas Pemetaan Tim
     - Inisiasi Kanvas Produk Data
     - Dokumen Wiki & Slide Presentasi: Dokumen Produk Data Baru dan Kepemilikan
     - Domain DataHub: Struktur Produk Data Baru
     - Clickup: Epic Produk Data Baru dan Penugasan
   - **Peran:**
     - Semua Anggota (Bertanggung Jawab)
     - Analis Tata Kelola Data (Bertanggung Jawab)
     - Arsitek Data (Mendukung)

## Output RASCI

- **R**: Bertanggung Jawab
- **S**: Mendukung

### Tanggung Jawab Peran

- **Analis Tata Kelola Data**
  - Bertanggung jawab untuk memastikan dokumentasi dan struktur domain serta produk data baru.
  - Mengawasi registrasi sumber input data dan pembuatan entri katalog.

- **Insinyur Data**
  - Bekerja sama dengan Analis Tata Kelola Data untuk mendaftarkan sumber input data.
  - Memastikan aspek teknis dari input data tercatat dengan benar.

- **Arsitek Data**
  - Mendukung Analis Tata Kelola Data dalam menyusun domain dan produk data baru.
  - Membantu dalam mendefinisikan arsitektur dan kerangka kerja untuk manajemen data.

Fase ini menetapkan dasar untuk manajemen dan tata kelola data yang efektif, memastikan kejelasan dalam peran dan output.
