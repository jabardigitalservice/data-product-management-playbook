# Design Phase

Fase Design adalah tahap di mana proses perencanaan dan arsitektur data dibentuk. Pada fase ini, tim akan merancang model data, infrastruktur, dan proses yang diperlukan untuk mendukung pengembangan produk data yang efektif.

![Design Phase Flow](media/design_phase.jpg ':size=100%')


## Alur Pekerjaan

1. **Business Process Research and Data Context**
   - **Deskripsi:** Melakukan penelitian tentang proses bisnis dan konteks data yang diperlukan untuk memahami kebutuhan pengguna.
   - **Output:** Laporan Penelitian Data Wiki Baru
   - **Peran:** Data Analyst (Bertanggung Jawab)

2. **User Research**
   - **Deskripsi:** Mengumpulkan informasi dari pengguna untuk memahami kebutuhan dan harapan mereka terhadap produk data.
   - **Output:** Laporan Penelitian Pengguna
   - **Peran:** Data Analyst (Bertanggung Jawab)

3. **Collect Metadata from Sources**
   - **Deskripsi:** Mengumpulkan metadata dari berbagai sumber untuk membangun pemahaman yang lebih baik tentang data yang tersedia.
   - **Output:** Metadata yang Dihimpun
   - **Peran:** Data Engineer (Bertanggung Jawab)

4. **Data Profiling**
   - **Deskripsi:** Melakukan analisis data untuk memahami kualitas dan karakteristik data yang ada.
   - **Output:** Laporan Profiling Data
   - **Peran:** Data Quality Analyst (Bertanggung Jawab)

5. **Design Data Model**
   - **Deskripsi:** Merancang model data yang akan digunakan dalam produk data.
   - **Output:** Model Data Dinamis
   - **Peran:** Data Architect (Bertanggung Jawab)

6. **Design Metadata Place**
   - **Deskripsi:** Menyusun tempat untuk menyimpan metadata yang diperlukan untuk pengelolaan data.
   - **Output:** Dokumen Metadata
   - **Peran:** Data Architect (Bertanggung Jawab)

7. **Data Quality Management Profile**
   - **Deskripsi:** Menyusun profil manajemen kualitas data untuk memastikan data yang digunakan berkualitas tinggi.
   - **Output:** Profil Manajemen Kualitas Data
   - **Peran:** Data Quality Analyst (Bertanggung Jawab)

8. **Data Volume Management**
   - **Deskripsi:** Mengelola volume data yang akan diproses dan disimpan.
   - **Output:** Rencana Manajemen Volume Data
   - **Peran:** DataOps (Bertanggung Jawab)

9. **Fill Request Form for Data Delivery**
   - **Deskripsi:** Mengisi formulir permintaan untuk pengiriman data sesuai kebutuhan pengguna.
   - **Output:** Formulir Permintaan Data
   - **Peran:** Semua Anggota (Bertanggung Jawab)

## Tanggung Jawab Peran

- **Data Analyst**
  - Bertanggung jawab untuk melakukan penelitian dan analisis data.
  - Menghasilkan laporan yang mendukung pengambilan keputusan.

- **Data Engineer**
  - Bertanggung jawab untuk mengumpulkan metadata dan membangun infrastruktur data.
  - Memastikan data dapat diakses dan diproses dengan efisien.

- **Data Quality Analyst**
  - Bertanggung jawab untuk melakukan profiling data dan memastikan kualitas data.
  - Mengembangkan strategi untuk meningkatkan kualitas data.

- **Data Architect**
  - Bertanggung jawab untuk merancang model data dan arsitektur sistem.
  - Memastikan bahwa desain memenuhi kebutuhan bisnis dan teknis.

- **DataOps**
  - Bertanggung jawab untuk mengelola proses pengiriman data dan memastikan kelancaran operasional.
  - Mengawasi manajemen volume data dan pemrosesan.

## Tantangan dan Mitigasi Risiko

1. **Tantangan: Kualitas Data yang Buruk**
   - **Mitigasi:** Melakukan profiling data secara menyeluruh dan menerapkan standar kualitas data yang ketat.

2. **Tantangan: Ketidakjelasan Kebutuhan Pengguna**
   - **Mitigasi:** Melakukan penelitian pengguna yang mendalam dan berkolaborasi dengan pemangku kepentingan untuk memahami kebutuhan mereka.

3. **Tantangan: Komunikasi yang Buruk dalam Tim**
   - **Mitigasi:** Mengadakan pertemuan rutin dan menggunakan alat kolaborasi untuk memastikan semua anggota tim berada pada halaman yang sama.

4. **Tantangan: Perubahan dalam Lingkungan Bisnis**
   - **Mitigasi:** Membangun fleksibilitas dalam desain untuk memungkinkan penyesuaian cepat terhadap perubahan kebutuhan bisnis.

5. **Tantangan: Keterbatasan Sumber Daya**
   - **Mitigasi:** Mengelola sumber daya dengan bijak dan memprioritaskan tugas-tugas yang paling penting untuk keberhasilan proyek.

Fase ini sangat penting untuk memastikan bahwa produk data yang dikembangkan memenuhi kebutuhan pengguna dan dapat diandalkan dalam pengambilan keputusan.
